# Project Initialization Plan

## Goal

Create a maintainable React + Vite + TypeScript foundation for a restaurant landing page, with a reusable vanilla CSS design system ready for later content phases.

## Implementation Steps

1. Create the Vite React TypeScript application structure.
2. Add TypeScript project references and strict compiler settings.
3. Add ESLint for TypeScript and React hooks checks.
4. Define brand tokens for color, typography, spacing, radius, and shadow.
5. Build a starter screen using reusable layout, navigation, button, card, and media primitives.
6. Verify `npm run build` and `npm run lint`.

## Branding Direction

- Warm editorial restaurant aesthetic without relying on a single-hue palette.
- Crisp off-white page base, deep ink text, wine accent, herb green support, and brass highlights.
- High-contrast typography with refined spacing and compact reusable components.
- Image-led layout patterns reserved for later phases; Phase 1 uses CSS placeholders that can be replaced with real photography.

## Acceptance Criteria

- The project installs with `npm install`.
- `npm run dev` starts a Vite development server.
- `npm run build` produces a production bundle.
- `npm run lint` passes.
- The starter page demonstrates the design system and responsive layout primitives.
