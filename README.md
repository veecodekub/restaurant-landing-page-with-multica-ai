# Restaurant Landing Page

React + Vite + TypeScript starter for a restaurant landing page project.

## Stack

- React 19
- Vite 8
- TypeScript 6
- Vanilla CSS design system
- ESLint

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
npm run preview
```

## Design System

The first pass lives in `src/styles.css` and defines:

- Brand palette and semantic tokens
- Responsive type scale
- Layout containers and section spacing
- Button, card, navigation, and media-frame primitives
- Starter restaurant content modules for future phases
